# Domain docs

This is a single-context repository.

Before exploring or changing code, engineering skills should read:

- `CONTEXT.md` at the repository root for the project glossary and domain boundaries.
- Relevant decisions under `docs/adr/`.

If either location is absent, proceed silently. Use the glossary's exact vocabulary in tests, code, and planning. If a proposed change conflicts with an accepted ADR, surface the conflict instead of silently overriding it.
